# Documentation index

> **Note on the product name.** This product was renamed from **Ameya Heights OS**
> to **Ordence** in August 2026. Forward-looking documents in this folder use the
> new name. The dated records below — the per-phase deployment logs, the phase
> notes and the versioned security reports — are left exactly as written, under
> the name the product had at the time. They are records of what happened, not
> descriptions of what the product is, and editing them would make them lie.
